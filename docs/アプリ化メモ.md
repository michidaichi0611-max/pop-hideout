# スマホアプリ化メモ

現状は Web（HTML5 Canvas）で作ってあり、そのまま次の3段階でアプリにできる。

## 1. いますぐ：ホーム画面に追加（PWA）
- `manifest.json`・アイコン（`icons/`）・全画面表示・縦固定を設定済み。
- `スマホ確認用サーバー.bat` で配信 → スマホのブラウザで開き「ホーム画面に追加」。
  ※ 本格的な PWA（オフライン起動）には HTTPS 配信と Service Worker が必要。今回は未導入。

## 2. ストア配信：Capacitor で包む（推奨）
Web のコードをそのまま iOS / Android アプリにする。必要なもの：Node.js、Android Studio（Android）、Mac と Xcode（iOS）、各ストアの開発者登録。

```
npm init -y
npm i @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios @capacitor/haptics
npx cap init "Pop Hideout" com.example.pophideout --web-dir www
（index.html・src・assets・icons・manifest.json を www/ にコピー）
npx cap add android
npx cap add ios
npx cap open android
```
- 振動は iOS の Safari では `navigator.vibrate` が効かないため、アプリ化時に `@capacitor/haptics` に差し替える（`src/game.js` の `vibe()` 1か所）。
- 画面の縦固定・ステータスバー非表示・ノッチ対応（`env(safe-area-inset-top)` 読み取り済み）を確認する。
- 保存は localStorage のままでも動くが、アプリでは `@capacitor/preferences` へ移すと消えにくい。

## 3. 本格エンジンへ移す場合（未決）
