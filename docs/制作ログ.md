# 制作ログ（試作 v0.1 / 2026-10-20）

## 制作統括のまとめ
- 目的：縦画面・片手操作の「探す→狙う→撃つ→時間を延ばす→短く移動」を最後まで遊べる試作。→ 達成。
- 優先順位：操作とゲームループ ＞ 敵の動き ＞ 演出 ＞ 見た目の仕上げ。
- 決定の記録は `ASSUMPTIONS.md`。数値の一元管理は `src/config.js`。
- 既存データの保護：作業フォルダは空。受け取った資料は `art_reference/` と `docs/` にコピーし、原本は変更していない。
  切り出した素材は `assets/` に自動生成（`tools/prepare_assets.py` で何度でも再生成可能）。

## 各部署の報告

### ゲームデザイン部
- 操作：押す→ドラッグで狙う→離して撃つ／軽いタップは押した位置を撃つ。照準は指の 70px 上に、押してから 0.12 秒かけてずれる。
- 時間制：全体 60 秒＋ボーナス、エリア 15 秒、移動 0.9 秒（移動中は時間・射撃・出現を停止）。
- 難易度曲線：4 段階。人数・顔を出す時間・隠れる時間・走る速さ・逃げる割合で上げる。遮蔽物は固定。
- 未解決：ボーナス量・難易度の最終値は実機プレイで調整が必要。

### アート部
- 背景 3 枚は設定画をそのまま使用。遮蔽物は背景画像の一部を手前に描き直す方式（素材追加なし、軽量）。
- 敵・主人公・エフェクトは設定画から自動で切り抜き、縁の色にじみを除去。
- 未解決：主人公 A は B の色替えによる代用。のぞき・狙い・被弾の専用フレームは無い。

### プログラム部
- 入力（Pointer Events、最初の 1 本の指のみ）、照準、ヒットスキャン（楕円の当たり＋遮蔽物による遮り＋奥行き順）、
  時間・エリア遷移・スコア・保存（localStorage）を `src/game.js` に実装。
- テスト・調査用に `window.PH_GAME`（内部状態と操作関数）を公開。`?seed=` で敵の出方を再現可能。

### アニメーション・VFX・サウンド部
- 敵：顔出し／横からのぞく／走る／逃げる、被弾時は「へこむ→跳ねる→薄れる」。血の表現なし。
- 拳銃：発射光＋短い弾道＋火花。水鉄砲：短い水流＋水しぶき。外れは土煙または小さなしぶき。
- 移動：主人公の走りポーズ＋上下動、足音 3 回。ボスの前に星のきらめき＋高い音。
- 効果音はすべて WebAudio 合成（音声ファイル無し）。右下の武器ボタン、左下の音ボタン。

### QA・パフォーマンス部
- 自動テスト `?test=1`：**32/32 合格**（Chromium 系の内蔵ブラウザ、540×960 表示）。
  項目は README の「テスト」を参照。通しプレイでは 4 種の敵と隠れる・のぞく・走る・逃げる・被弾の全状態の出現を確認。
- 「見えている部分を狙えば必ず当たる」ことを自動プレイで確認（96/96）。遮蔽物の陰・完全に隠れた敵は当たらない。
- HUD 帯・武器ボタン・一時停止ボタンを押しても発射しないことを確認。
- 負荷：描画＋更新で 1 フレーム約 0.3〜0.4ms（CPU）。画像は合計約 1MB、エフェクトは低負荷時 10 個まで。
  動的ライト・影・物理演算・パーティクルシステムは使っていない。見えない敵・遠景は更新しない。
- 未確認：実機スマホでの操作感と FPS、file:// 直接起動（ASSUMPTIONS.md 参照）。

## 再現手順（確認方法）
1. `python -m http.server 8123` をこのフォルダで実行し、`http://localhost:8123/?test=1` を開く → 左上に結果。
2. `http://localhost:8123/?debug=1` で遊ぶと、当たり判定（緑＝撃てる／赤＝撃てない）、精密判定の円（水色）、遮蔽物の枠、FPS が見える。

# 制作ログ（v0.3 手応えの作り直し / 2026-10-21）

ユーザー指摘：「エフェクトや弾道線が安っぽい」「照準は当たった瞬間だけ中が変わるように」。

## 変更点
- 照準：狙っている間は色を変えない（構えると少し絞られるだけ）。
- **ヒットマーカー**：当たった瞬間だけ、撃った位置に×印がポンと出る。通常＝白、精密＝金＋光、ボス＝赤＋光。外れは照準の残像が縮んで消える。音も「カチッ」（精密は「キンッ」）。
- 弾道：細い線 → 先端が太く光り、尾に向かって細く消える光の筋（加算合成）＋先端の光。
- 発射：銃口の光（グロー）＋発射光の絵＋小さな硝煙。
- 命中：白い閃光 → 衝撃波の輪（精密・ボスは二重）→ 速度方向に伸びる火花 → 着弾の絵 → 煙、の重ね表現。
- 敵：撃たれた方向へ吹っ飛びながら回転。
- 数字：金・白・赤のグラデーション文字で、ポンと大きく出て少し戻り、ふわっと上がる。精密は「CRITICAL!」。
- カメラ：命中時にわずかにズームが寄る（パンチ）。精密は一瞬長めに止まる。
- 得点欄はコイン到着時に光る。コンボ数は命中ごとに弾む。掛け声もグラデーション文字＋光。
- 水鉄砲：点の連なり → ひと続きの水流（先端が太く、少し下へたわむ）＋水滴。

## QA
- 自動テスト 41/41 合格（390×844）。
- 負荷：射撃を続けた状態で約 0.4〜0.5ms/フレーム（低負荷）、約 1.2ms（標準）。光は事前に作った画像を加算で描くだけ。
