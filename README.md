# ポップ・ハイドアウト（仮称）— 縦画面の試作

西部劇風 2.5D の片手操作・標的シューティングの縦切り試作です。
HTML5 Canvas 2D だけで動き、ビルドやインストールは不要です。

## 起動

| 方法 | 手順 |
|---|---|
| PC ですぐ遊ぶ | `起動.bat` をダブルクリック（または `index.html` をブラウザで開く） |
| スマホで遊ぶ | `スマホ確認用サーバー.bat` を起動 → 同じ Wi-Fi のスマホで `http://<PCのIP>:8000/` |
| 開発用 | `python -m http.server 8123` → `http://localhost:8123/` |

URL の末尾につけるオプション：`?debug=1`（FPS・当たり判定・遮蔽物の枠を表示）、`?test=1`（自動テスト）、`?seed=123`（敵の出方を固定）。

## 操作

- **引いて狙う（標準）**：画面を押すと押した所の少し上に照準が出て、指を**後ろ（下）へ引くほど照準が上へ**、左へ引くと右へ動きます（弓・パチンコ式、引いた量の 1.3 倍）。**離すと発射**（ヒットスキャンで即時判定）。
- 設定の「撃ち方」で切り替えられます（**引いて**／**なぞって**：照準が指先の約 70px 上について動く／**タップ**：指の位置をそのまま撃つ）。マウスも同じ操作です。
- **エイムアシスト（標準でオン）**：少しだけ外れた弾（敵から 28px 以内）は、見えている敵に当たります。町の人には吸い寄せられません。設定でオフにできます。
- 上部の HUD 帯（時間・得点・一時停止）と、下部の武器／音ボタンを押しても撃ちません。
- PC キー：`Q` 武器切替、`Esc` 一時停止。

## 遊びの流れ

敵を探す → 押して狙う → 離して撃つ → 命中 → ボーナスで残り時間を延ばす → 15 秒ごとに 0.9 秒の横移動で次のエリアへ（移動中はタイマーと射撃が止まる） → 時間切れで結果。

- エリア：酒場・大通り・幌馬車通り・鉱山・牧場・駅の 6 種（プレイごとに順番が変わる）。大通りと駅は窓から、鉱山は足場の上からも敵が出る
- 敵：赤い隠れ屋（上から顔を出す）、緑の走り屋（遮蔽物の間を走る・最後に逃げる）、青い慎重派（遅れて横からのぞく）、金色のボス（2 エリア目以降。帽子の星がきらっと光った後、奥の柵などから少しだけ顔を出す）
- 難易度はエリアごとに上がる：同時人数・顔を出す時間・隠れる時間・走る速さ・逃げる割合
- 得点：命中 100、精密（顔の中心付近）+50、コンボで倍率（最大 2 倍）、ボス +1000
- 時間ボーナス：精密 +0.3 秒、3 コンボ以上で命中ごと +0.3 秒、ボス +5 秒。外すとコンボが切れる
- 8 コンボでフィーバー（得点 2 倍）。結果はランク S/A/B/C
- 武器：拳銃（発射光・短い弾道・火花）／水鉄砲（短い水流・水しぶき）。当たり判定は共通
- ベストスコア・選んだキャラ・武器・画質・BGM/効果音/振動の設定はブラウザに保存

スマホアプリとしての配信方法は `docs/アプリ化メモ.md`。

## ファイル構成

```
index.html            入口
manifest.json, icons/ ホーム画面追加用
src/audio.js          効果音と BGM（WebAudio 合成）
src/meta.js           ミッション・ランキング・ショップ
src/config.js         調整用データ（時間・得点・ボーナス・難易度・遮蔽物座標・画質）
src/game.js           本体（入力・照準・判定・敵 AI・エリア移動・描画・効果音合成・保存）
tests/tests.js        自動テスト（?test=1 で実行）
tools/prepare_assets.py  art_reference/ から assets/ を切り出すスクリプト
assets/               試作用に切り出した画像（自動生成。手で編集しない）
art_reference/        受け取った設定画（原本のコピー。変更しない）
art_new/              画像生成した追加素材の元画像（主人公の構え・走り、ロゴ、WANTED）
docs/                 受け取った仕様書・指示文、制作ログ
ASSUMPTIONS.md        仮に決めたことと未決事項
```

## 調整のしかた

数値はすべて `src/config.js` にあります。保存してブラウザを再読み込みするだけで反映されます。
例：エリアの長さ `time.areaDuration`、初期時間 `time.initial`、ボーナス `bonus.*`、難易度 `levels[]`。

画像を差し替えたら `python tools/prepare_assets.py` で `assets/` を作り直します（numpy・Pillow・scipy が必要）。
